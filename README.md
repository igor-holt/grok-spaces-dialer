# Grok Spaces Dialer

Phone-first interface to X Spaces. Call a number, talk to Grok, pick a room.

Public tools webhook (Cloudflare Worker):
https://grok-spaces-dialer.iholt.workers.dev/health

Repo: https://github.com/igor-holt/grok-spaces-dialer
Linear: https://linear.app/kovachenterprises/project/grok-spaces-dialer-e09a2cf31c98

Discovery MVP uses fixtures on the Worker. Live X search requires X_BEARER_TOKEN.
Audio bridge is not in production.
